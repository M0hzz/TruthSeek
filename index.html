TruthSeek

Pin it up. Follow the string.

Drop a JSON file of nouns, relationships and events anywhere on this page. TruthSeek pins them to a board, plays the events in order and shows you the ripples you did not write down.

What should the file look like? 
{
  "title": "My board",
  "nouns": [
    { "id": "guild", "name": "The Guild", "type": "faction", "weight": 5 },
    { "id": "mara", "name": "Mara", "type": "person", "weight": 2,
      "parent": "guild", "context": "Keeps the books." }
  ],
  "relationships": [
    { "from": "mara", "to": "guild", "type": "embezzles from",
      "strength": -0.4, "direction": "one-way" }
  ],
  "events": [
    { "name": "The Audit", "time": 1204,
      "effects": [ { "target": "mara", "power": -1 } ] }
  ]
}

Impact engine

How power spreads through the board. Saved into the file when you export.

Using TruthSeek

On the board

  • Click a card or string to inspect it. Click empty board to clear.
  • Drag a card to move it; it stays where you leave it. Drag the board to pan; scroll to zoom.
  • Shift-drag from one card to another to tie a new string.
  • Double-click a card to fold its members inside it (and again to unfold).
  • Keys: ← → step through events, Space plays, F fits, Esc clears, Delete removes the selection.

How power is worked out

  • Every noun starts with its weight. Events add to or take from it.
  • A noun that contains others gains a share of their power (members → container), and passes a share of its own down to them.
  • Power ripples along strings: each hop multiplies by the string's strength, and every hop after the first also by the falloff. Negative strengths carry opposition.
  • Total power = own power + members + everything arriving through strings.

File format

{
  "title": "…",
  "nouns": [{
    "id": "unique_id", "name": "Shown name", "type": "person",
    "weight": 3,                 // importance, default 1
    "parent": "other_id",        // the noun it sits inside
    "context": "Free text",      // its own back-story
    "tags": ["a", "b"],
    "exists": false              // optional: not there at the start
  }],
  "relationships": [{
    "from": "id", "to": "id", "type": "funds",
    "strength": 0.7,             // −1 opposes … +1 supports
    "direction": "one-way"       // or "two-way" (default)
  }],
  "events": [{
    "name": "…", "time": 1204,   // number or date like "2024-03-01"
    "description": "…",
    "involves": ["id"],
    "effects": [
      { "target": "id", "power": -2 },
      { "target": "id", "parent": "new_container_id" },
      { "target": "id", "exists": false },
      { "relationship": ["from_id", "to_id"], "strength": 0.3 },
      { "link": { "from": "id", "to": "id", "type": "allies",
                  "strength": 0.5, "direction": "two-way" } },
      { "unlink": ["from_id", "to_id"] }
    ]
  }]
}

Extra fields you add are kept when you export.
